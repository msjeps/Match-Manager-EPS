🔑 Mot de passe personnalisé (optionnel)

Cet accès est protégé par le mot de passe par défaut (voir le guide professeur). Vous pouvez définir ici un mot de passe qui vous est propre - une fois personnalisé, le mot de passe par défaut ne fonctionne plus directement (pour empêcher un élève qui le connaîtrait de contourner votre mot de passe). En cas d'oubli, 3 tentatives incorrectes sur l'écran de connexion font apparaître un bouton pour réinitialiser au mot de passe par défaut.
